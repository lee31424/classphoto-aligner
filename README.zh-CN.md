# ClassPhoto Aligner / 照片名单对齐工具

用于把**固定顺序的学籍照片队列**与 **Excel 名单**按位置对齐，并按班级批量导出为 `学号.jpg`。不使用人脸识别，核心规则是：

> 第 N 张照片 = 当前名单第 N 条学生。

适合按学院、专业、班级分批处理大量学生证件照的场景。

## 功能

- 照片按文件名自然排序，导入后顺序固定，界面不允许拖动照片。
- 支持 `.xlsx` / `.xlsm` / `.xls` 名单。
- 名单可选导入：学号、姓名、院系、班级、性别。
- 性别只显示 **男 / 女**。
- 每个班级一个班级框；点班级框同时筛选照片和名单。
- 选择院系后，班级框和班级号下拉只显示该院系的班级。
- 右侧名单根据窗口宽度自动 2 列 / 3 列显示。
- 选到具体班级后，可在本班内拖动调整顺序、删除未到场学生。
- 照片右键“删除照片”只从队列移除，不删除磁盘源文件，可撤销。
- 名单右键“删除未到场”或“移到名单/本班末尾”，均可撤销。
- 按班级导出：`导出路径/学院/专业/班级/学号.jpg`。
- 每导出一个班，班级框显示 **✓ 已导出**，并保存标记。
- 后台复制、进度、取消、断点续跑、CSV 日志、JSON 汇总、按日志撤销。
- 4000+ 张照片使用缩略图虚拟化，不会一次性解码全部图片。

## 路径中的学院/专业/班级

导入照片时选择**根目录**，工具会递归扫描子文件夹。示例：

```text
学籍机械/机械26211/IMG_0001.JPG   -> 机械工程学院 / 机械 / 26211
北校区/26621/IMG_0002.JPG         -> 汽车工程学院 / 汽车 / 26621
学籍262401班/IMG_0003.JPG          -> 机械工程学院 / 机械 / 262401
```

路径里的“机械”“北校区”等简称，会在导入名单后用相同班级代码对应的完整院系名校正。

## 快速开始

要求：Windows 10/11、Python 3.13+（64 位）。

```powershell
git clone https://github.com/lee31424/classphoto-aligner.git
cd classphoto-aligner

py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt

.\run.bat          # 正常启动
.\run_debug.bat    # 带控制台启动，便于排错
```

## 使用流程

1. 导入照片根目录。
2. 导入 Excel 名单，确认学号、姓名、院系、班级、性别列。
3. 点班级框选择班级。
4. 在本班内拖动名单、删除未到场学生。
5. 在顶部填写导出路径。
6. 点 **修改并导出本班**，立即导出当前班。
7. 接着选下一个班级。

如果当前班照片数与名单人数不一致，工具会阻止导出并提示先处理差值。

## 输出结构

```text
导出路径/
└─ 机械工程学院/
   └─ 机械/
      └─ 26211/
         ├─ 2621101.jpg
         ├─ 2621102.jpg
         ├─ rename_plan_*.csv
         ├─ rename_log_*.csv
         └─ rename_summary_*.json
```

- 源照片只读，不会被改名、移动或删除。
- 输出目录必须位于照片源目录之外。
- 已存在且大小一致的目标文件会跳过，可用于断点续跑。
- 撤销只删除日志中状态为 `ok` 且大小校验一致的文件。
